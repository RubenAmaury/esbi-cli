# esbi-cli documentation

esbi-cli (`sb`) turns the PDFs, links and emails you save into a Markdown wiki of notes, written by a local or cloud language model. These pages show how to install it, use it, and look things up. The notes it writes are in the language you choose (English or Spanish); the documentation and the command line are in English.

## How the documentation is organised

- **Learn** is a guided path with every output shown.
- **Do** is one recipe per task.
- **Look up** is complete and exact: commands, settings, files.
- **Understand** explains why, with measurements where they exist.

Version 0.x: it works and is used daily, but commands and the config format can still change between minor versions; see the [changelog](https://github.com/RubenAmaury/esbi-cli/blob/main/CHANGELOG.md).
